# Contributing to clj-shacl

## Discussions

Use [Discussions](https://github.com/dcj/clj-shacl/discussions) for questions about using the library or the CLI, API and design ideas, and sharing what you build with it. A Discussion that reaches a clear, agreed scope can become an Issue.

## Issues

Use [Issues](https://github.com/dcj/clj-shacl/issues) for actionable changes: a validation result that differs from the SHACL specification or from another conforming engine, a JSON-LD document that parses incorrectly, a CLI defect, or a documentation error. Include the smallest data and shapes graphs that reproduce it, the command or code you ran, and what you expected.

Report security vulnerabilities privately, as described in [SECURITY.md](SECURITY.md).

## Pull requests

Small fixes can go straight to a pull request. For a new function, option or behavior, open a Discussion or Issue first so the scope is agreed before you invest the effort.

Every change passes:

```bash
clj-kondo --lint src test dev
clojure -M:test
```

A behavior change comes with a test that states it. Contributions are accepted under the [MIT License](LICENSE).

## Development

```bash
clojure -M:test     # Kaocha test suite
clojure -M:nrepl    # nREPL on port 7897
clojure -M:cli ...  # run the CLI from source
```

`test/resources/fixtures/ontology-inoculated.nt` is generated by `dev/inoculate_expected.py` with pyshacl; regenerate it when the inoculation fixture ontology changes.

## Important notice

This library is provided on an "as-is" basis. Maintenance, including responses to issues, happens as time and resources permit.
